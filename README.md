# TASK — AI social companion

Monorepo de TASK, un compagnon social IA : une personne numérique avec laquelle l'utilisateur
construit une relation qui évolue (texte, vocaux, appels, vidéo, stories, initiatives).

- `docs/ARCHITECTURE.md` — architecture technique complète (référence).
- `docs/PHASES.md` — plan de phases et état d'avancement.
- `apps/api` — backend Fastify/TypeScript (moteurs, providers, workers).
- `apps/web` — client web PWA mobile-first.
- `packages/shared` — schémas Zod et types partagés.
- `infra/` — Docker Compose de dev et `.env.example`.
- `trading-journal/` — projet précédent, indépendant et intact.
